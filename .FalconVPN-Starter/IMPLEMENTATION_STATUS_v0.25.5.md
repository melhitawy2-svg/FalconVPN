# Falcon VPN v0.25.5 — Server tier chooser UI

- Added three horizontally aligned server-tier tabs: General, Plus, Pro.
- General is selected by default.
- General tier shows the 22 Arab League countries in a compact flag/country grid.
- Selecting a country opens a country-specific server list in the same modal, with a back-to-country-list action.
- Plus and Pro show locked subscription panels.
- Existing v41 visual design and the existing service-configuration form are preserved.

## Limitations
- Country-specific server entries are clearly marked as placeholders; no real server configs were invented.
- Plus/Pro purchase and subscription verification are not connected.
- This source preview was not built as an APK or device-tested in this environment.
